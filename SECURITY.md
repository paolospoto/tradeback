# Security policy

Tradeback runs entirely in the browser: save files are read and written on the device and never sent
to a server. The only third-party requests are for Pokémon artwork (PokéAPI sprites on GitHub).

## Reporting a vulnerability

Report it privately through [GitHub security advisories](https://github.com/paolospoto/tradeback/security/advisories/new).
Do not open a public issue. Expect a first answer within a week.

Only the latest release is supported.
